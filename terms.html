利用規約

最終更新：2026年10月20日

「図鑑チャンネル投稿管理」は、運営者本人が管理権限を持つYouTubeチャンネルの投稿・字幕・公開予約を管理するためのローカルアプリです。

利用対象と操作

本アプリは運営者本人の利用を対象とし、一般向けのアカウント登録や課金機能は提供しません。投稿先、動画の内容、公開状態、日時は、運営者の指示と確認に従って指定します。Googleへの認証は投稿内容の公開許可の代わりにはなりません。

投稿内容と権利

投稿する動画・画像・音声・字幕について、利用する権利と、必要な出典・開示・公開設定を確認します。YouTubeのルールと利用資格に従って利用します。

YouTubeとGoogleの条件

本アプリはYouTube API Servicesを利用します。本アプリを使用することにより、利用者はYouTube利用規約に拘束されることに同意します。利用にはYouTube利用規約、YouTube API Services Terms of ServiceおよびGoogle API Services User Data Policyが適用されます。

利用上の制約

Googleの認証、APIの利用枠、YouTubeの投稿上限、動画・字幕の処理状況などにより、操作が完了しない場合があります。完了を確認できない処理は、結果を照合してから再開します。これらの制限を回避する目的では使用しません。

プライバシーと問い合わせ

情報の取り扱いはプライバシーポリシーに定めます。問い合わせ先はGoogleの認証画面に表示されるサポートメールです。
