プライバシーポリシー

最終更新：2026年10月20日

本ポリシーは、YouTube API Servicesを利用し、運営者本人のチャンネル管理に使用するローカルアプリ「図鑑チャンネル投稿管理」に適用されます。Google側のデータの取り扱いについては、Googleプライバシーポリシーをご参照ください。

取得・使用する情報

Googleの認証で許可されたチャンネルのID・名称、動画のID・タイトル・説明・公開状態・予約日時・処理状態、字幕の登録状態を取得します。投稿する動画・字幕ファイルと投稿設定は、運営者がこのMac上で指定します。

これらの情報を、依頼された動画の投稿、字幕登録、公開予約、結果確認と重複投稿の防止に使用します。Googleのパスワードは取得しません。

Googleのアクセス許可

動画と字幕の管理に必要なYouTube APIの権限を要求します。Googleの許可画面では、動画などの確認・編集・削除を含む広い権限が表示される場合があります。本アプリの実装には、動画やコメントを削除する操作は設けていません。

保存場所と管理

OAuthクライアント情報、アクセストークン・更新トークン、アップロードを再開するための情報は、運営者のMacのキーチェーンに保存します。動画・字幕・投稿ID・実行記録は、このMacの制作フォルダまたは専用のアプリケーションデータフォルダに保存します。

保存データは運営者が管理します。Googleから取得した状態は必要な操作時に再確認し、過去の記録を現在の公開状態として扱いません。

外部サービスとの通信

認証・動画投稿・設定確認のためGoogleと通信します。Codexから操作する際は、運営者の依頼、投稿内容、APIから取得した確認結果が、ご利用のCodexサービスで表示・処理されます。Codex側のデータの取り扱いには、そのサービスの規約・ポリシーと運営者の利用設定が適用されます。

本アプリは、認証情報をチャットへ返したり、広告配信・データ販売・AIモデルの学習用データセット作成に情報を使用したりする機能を設けていません。

この案内ページはGitHub Pagesで配信し、広告や独自のアクセス解析スクリプトは置いていません。GitHubは、安全な運用のため閲覧者のIPアドレスを記録・保存します。詳しくはGitHubのプライバシー声明をご参照ください。

GoogleのLimited Useへの対応

Google APIから受け取った情報の利用と他のアプリへの転送は、Google API Services User Data Policyに従い、Limited Useの要件を含めて取り扱います。

アクセス許可の取り消し・削除

Googleアカウントのセキュリティ設定から、本アプリのアクセス許可を取り消せます。保存済みの認証情報はMacのキーチェーン、実行記録は専用フォルダから削除できます。これらを削除しても、YouTubeに投稿済みの動画は自動削除されません。

お問い合わせ・変更

本アプリの利用者は運営者本人です。問い合わせ先は、Googleの認証画面に表示されるサポートメールです。データの取り扱いを変更する場合は、本ポリシーを更新します。
